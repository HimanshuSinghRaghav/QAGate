# 6. This is why the transcript is intentionally messy

# 20. A very strong scoring strategy for this transcript

I would make your engine operate in three layers.

### Layer 1 — Deterministic

Use code for things like:

```text
numbers
prices
dates
emails
phone
boolean questions
CRM values
plan values
```

### Layer 2 — Semantic

Use an LLM/model for:

```text
script equivalence
whether a response satisfies a requirement
objection handling
rapport
whether a correction superseded an earlier statement
```

### Layer 3 — Human escalation

Use QA when:

```text
low confidence
ambiguous facts
conflicting conversation state
critical uncertainty
```

That is much more defensible than "GPT checks everything."
