# Bugs (how to use)

This folder is for **real issues** found in the backend, frontend, and/or docs.

When you create a new bug note:

1. Copy `knowledge/_templates/Bug.md`.
2. Fill symptom, repro, root cause, fix/workaround.
3. Link the affected modules: `[[03 Modules/...]]`

Keep old bug notes. Move confirmed fixes to `status: resolved`.
