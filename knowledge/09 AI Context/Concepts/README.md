# Concepts (atomic notes)

Rule: **one idea per note**. Concepts are reusable mental-model pieces that help agents and humans stay consistent across sessions.

### When to create a concept

- A concept shows up in multiple modules/features.
- You find yourself copying the same explanation again and again.
- You want an “agent can cite this” anchor for prompts/rules.
