# Meetings (how to use)

This folder is for notes that you actively use to drive work.

Rule: do not create fake meetings; only capture when you had a real discussion.

## Recommended workflow

1. Create a new note using `knowledge/_templates/Meeting.md`.
2. Fill date, attendees, agenda, decisions, action items.
3. Promote follow-ups to `00 Inbox/`, `07 Bugs/`, or `08 Decisions/` as needed.

Hackathon briefs live in the repo as `backend/overview/1.md` (product) and `backend/overview/2.md` (transcript). They are source material, not meeting notes.
