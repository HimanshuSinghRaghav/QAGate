# Inbox (capture + triage)

This folder is for **fleeting notes** and **session handoffs**. Everything lands here first, then you promote it into the right place.

## What goes here

- “I just discovered X” notes
- Bug sightings before you understand root cause
- Decisions that need follow-up
- Session handoff notes created at the end of each coding session

## Promotion targets

- Architecture: `02 Architecture/`
- Module updates: `03 Modules/`
- Database relationships: `04 Database/`
- Feature-level summaries: `06 Features/`
- Incidents/bugs: `07 Bugs/`
- ADRs/tradeoffs: `08 Decisions/`
- Reusable prompts: `10 Prompts/`
- Meetings: `11 Meetings/`

## Session handoff template

Create/update one note under `00 Inbox/` named like:

- `Session-Handoff-YYYY-MM-DD.md`

Use `knowledge/_templates/Session Handoff.md` as the skeleton.
